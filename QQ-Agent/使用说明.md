## 1. 环境要求

- Windows 10 / 11 64 位
- **不需要装 Node.js、不需要 `npm install`**：Electron 运行时和 SnowLuma 的 `node.exe` 都在包里
- 磁盘：解压后约 380 MB，运行后数据再占几十 MB
- 建议：放在**非同步盘**（OneDrive / 坚果云 / 360 云盘等可能漏同步或锁住 `.exe`），路径别太深
- 杀毒软件可能误报 `electron.exe` / `node.exe`（Electron / Node 官方二进制的常见误报），需要时把它们加白名单

## 2. 三步跑起来

### 第 1 步：解压 + 启动

1. 把 zip **完整解压**到任意目录（例：`D:\QQ-Agent-爆改版`）。⚠️ 不要在压缩包预览窗口里直接双击。
2. 双击目录里的 **`启动QQ机器人.bat`**。
   - 它会用自带的 Electron 启动界面窗口，并**自动拉起 SnowLuma**（用自带的 `node.exe`，无黑窗）。
   - 窗口没出现？看托盘 / 任务栏；界面也可以用浏览器打开 **`http://127.0.0.1:3210`**。
3. 此时状态栏显示 `OneBot 未就绪` 是正常的 —— 因为还没登录 QQ。

### 第 2 步：登录 QQ（SnowLuma 桥）

1. **先找到 WebUI 初始密码**（第一次运行才有，一定要先做这一步）：
   应用是**无窗口**拉起 SnowLuma 的，所以初始凭据打印在日志里 —— 用记事本打开
   **`data\logs\snowluma-console.log`**，搜索 `initial credentials`，会看到这样一行：

   ```
   [WebUI] initial credentials: user=admin password=f179676d0388d8a4
   ```

   —— `user=admin`，密码就是后面那串随机字符（每个人的都不一样）。
   > 找不到时：也可以看 `snowluma\logs\snowluma-日期.log`；或者手动双击 `snowluma\launcher.bat`，黑窗口里会直接把凭据打出来。
   > ⚠️ 这串密码**只显示这一次**。登录后**立刻改掉**；如果你一路跳过没改，下次启动会自动生成新的随机密码，同样打印在日志里。

2. 浏览器打开 **`http://127.0.0.1:5099`** → 这是 **SnowLuma 控制台**，用 `admin` + 上面的初始密码登录。
3. 登录后**先同意 EULA / 隐私政策**（此时面板还没解锁；协议原文就在 `snowluma\EULA.md`、`snowluma\PRIVACY.md`），然后**改掉 WebUI 密码**，再**登录你要挂机器人的那个 QQ 号**（扫码或账号密码，按它界面提示来）。
4. 登录后在 SnowLuma 里新建一个 **OneBot 网络**：
   - **WS 服务端**：`ws://127.0.0.1:3001`
   - **HTTP 服务端**：`http://127.0.0.1:3000`
   - 如果设了 **access token**，**SnowLuma 那边和应用这边必须填得一模一样**。
5. 回到应用窗口 → `设置 → SnowLuma · OneBot` → 填 `ws://127.0.0.1:3001`、`http://127.0.0.1:3000` 和对应 token → **保存设置**。
   状态栏变成 `OneBot 已连接` 就成功了。

### 第 3 步：配模型 + 白名单（不做这步 bot 不会说话）

1. `设置 → 模型 API`：点击 **DeepSeek / GLM / GPT**，选择模型，在弹窗填写 **API Key** 并点 **保存并使用**，地址自动填写，立即生效；再点 **测试连通性** 验证账号权限。
   - DeepSeek 提供 V4.1 Flash、V4 Pro；GLM 提供 5.3、5.3 Flash、5.3 FlashX、5.2；GPT 提供 6.1 Sol、6 Astra、6 Sol、6 Luna。
   - 中转站、自建网关等在 **其他** 中填写 Base URL、API Key 与模型 ID，点击 **确认添加** 后使用首个模型。温度、思考和工具轮数在 **高级设置** 中，不修改就保留当前配置；修改高级参数后点顶部 **保存设置**。
2. `设置 → 聊天白名单`：把要它接活的**群号**填进去。
   - ⚠️ **留空 = 谁都不理**（这是默认的安全设置，不是 bug）。想让它在所有群都回，就打开「允许所有…」那项。
3. 去群里 **@ 它一下**，看有没有反应。

## 3. 12 个设置分栏分别管什么

| 分栏 | 管什么 | 提示 |
|---|---|---|
| **模型 API** | DeepSeek / GLM / GPT 预设接入，其他自定义供应商；高级设置包含温度、工具轮数、图片输入与思考模式 | 预设模型仅需填写 API Key；模型接入立即保存，高级参数点「保存设置」生效 |
| **搜索服务** | 联网搜索走哪家：Bing 网页解析（默认，**无需 key**）/ DeepSeek / 智谱 / 博查 / 百度 / 秘塔 / 自定义 | 默认 Bing 就够用，不需要额外申请 |
| **搜图服务** | 图源（pixiv / konachan …）、每群数量、R18、隐藏 AI 图、关键词屏蔽 | 图源连不上会**自动降级**到可用图源，并在回复里说明原因 |
| **记忆** | 长期记忆整理（合并周期、用哪个模型）、跨群档案、跨群私聊 | 关掉就是"无状态"模式 |
| **定时提醒** | 让它到点主动说话、错过后的补发 | 提醒触发时**私聊也一定会响应** |
| **风格学习** | 学群里的说话方式 / 图片反应 / 表情包 / emoji，可自动蒸馏 | 采样多了才有效 |
| **梗知识库** | 梗的注入与检索、自动记梗、用量记录 | 和「记忆」是两套，别搞混 |
| **人设** | 角色卡（可多张、可导入导出）、botName、参与度、追加自定义规则、触碰反应、R18 开关 | 本包已还原为内置的「小鲸鱼（默认）」 |
| **聊天白名单** | 允许 / 禁止的群与私聊、留空时的行为 | 新手最容易漏的一栏 |
| **聊天设置** | 发送节奏（间隔、每分钟/每小时上限）、上下文档位与条数、主动搭话、表情包、被禁言时的回应、管理员 | **私聊始终响应，不受档位影响** |
| **桌面端** | 主题、托盘、开机自启、界面刷新间隔 | 想让它开机就跑，在这里开 |
| **OneBot（SnowLuma）** | 桥地址与 token、自动拉起 SnowLuma、目录、连接测试 | 地址要和 SnowLuma 里配的一致 |

## 5. 常见问题

**Q：bot 完全不理人？**
按顺序查：① `聊天白名单` 是不是空的（默认空 = 不理任何人）；② 上下文档位是不是太低；③ 顶部是不是点了 **`暂停`**；④ 状态栏是不是 `OneBot 已连接`；⑤ `模型 API` 有没有配好并通过 `测试连通性`。

**Q：双击了启动脚本，没反应 / 窗口一闪就没了？**
99% 是**同名程序的单实例锁**在作怪：这个程序的 `package.json` 里 `name` 是 `qq-agent`，与其它 QQ Agent 共用 `%APPDATA%\qq-agent`，**只要已经有一份在跑，后启动的那份会在几百毫秒内静默退出**（不会有任何提示）。
处理：先打开任务管理器，看有没有 `electron.exe`（路径里带 QQ Agent / 新建文件夹），有就先退出（或托盘图标右键退出），再启动这一份。
**永远不要同时开两份** —— 它们还会抢 `3000/3001/5099` 端口和同一个 QQ 号。

**Q：端口占用起不来？**
`3000`、`3001`（SnowLuma）、`3210`（应用界面）、`5099`（SnowLuma 控制台）任一被占都会失败。用 `netstat -ano | findstr 3000` 找出占用进程并结束它。

**Q：搜图总是失败？**
pixiv 在国内常常直连不通。程序会**自动降级**到可用的图源（如 safebooru）并在回复里说明原因；也可以在 `搜图服务` 里直接固定成其它图源。

**Q：SnowLuma 起不来？**
看 `snowluma\logs\`；也可以手动双击 `snowluma\launcher.bat`（会开一个黑窗，报错能直接看到）。

**Q：进不去 SnowLuma 控制台 / 忘了 WebUI 密码 / 没记那次打印的初始密码？**
删掉 `snowluma\config\webui.json`（这个文件里存的是密码哈希），然后重启程序 —— 会**重新生成一组初始凭据并再次打印**到 `data\logs\snowluma-console.log`（搜索 `initial credentials`），用 `admin` + 新密码登录后马上改掉。
> 实测确认：有 `webui.json` 时不会再打印；删掉它重启就会重新生成。

**Q：想换一个 QQ 号？**
在 SnowLuma 控制台（`127.0.0.1:5099`）登出/换号，并在应用 `SnowLuma · OneBot` 分栏确认地址与 token 仍然一致。

**Q：怎么退出？**
关窗口即可退出（默认不驻留托盘）；如果开了托盘驻留，就在托盘图标上右键 → 退出。**退出后再启动才有效**（见上面的单实例锁）。

**Q：模型说"搜图/搜索不可用"？**
`搜索服务` 用默认 Bing 不需要 key；`搜图服务` 若图源被墙就换一个。工具本身都在，没有为了省 token 而删减功能（原版 36 个工具全保留）。

## 7. 这包比原始版改了什么

以下为已有修复与优化记录；当前版本另外移除了社区上传、推广和联网上报功能，保留聊天工具及设置分栏：

| 文件 | 改动 |
|---|---|
| `src/orchestrator.js` | **修复"内心独白被当成发言发出去"**（模型只写了思考文本、没调工具时的兜底守卫）；私聊与定时提醒必定响应；定时器句柄回收 |
| `src/app.js` | 崩溃/被杀后**自动恢复被中断的会话**；重复消息按 id 去重校验；识别"自己发的消息"更稳（不依赖桥返回登录信息） |
| `src/prompt.js` | 提示词**顺序**优化（内容一字未改），让 prompt 前缀缓存更容易命中、更省 token |
| `src/store.js` | 重复消息按 `mid` 去重，避免重复回应 |
| `src/sessions.js` | 中断会话的 `recoverStale()` 恢复；`discard()` 守卫 |
| `src/image-search.js` | 网络错误识别、图源冷却、**自动降级**到可用图源、过滤无效图片 URL |
| `src/persona-store.js` | 人设原文不再被截断写入 |
| `src/config.js`、`src/app.js`、`src/sessions.js` | 移除用量遥测及其专用累计逻辑，保留本地用量统计 |
| `src/tier-slider.js` + `ui/app.js` | 档位滑杆边界修正、标签说明更清楚 |
