========================================
 QQ Agent 爆改版 0.3.0 免安装版 —— 快速开始
========================================

【三步跑起来】

第 1 步  解压 + 启动
  - 把 zip 完整解压到任意目录（例：D:\QQ-Agent-爆改版）
    ⚠ 不要在压缩包预览窗口里直接双击
  - 双击目录里的  启动QQ机器人.bat
  - 界面 = 弹出的窗口，或浏览器打开  http://127.0.0.1:3210

第 2 步  登录 QQ（SnowLuma 桥）
  - 【先拿初始密码】用记事本打开   data\logs\snowluma-console.log
    搜索  initial credentials  ，会看到：
        [WebUI] initial credentials: user=admin password=xxxxxxxxxxxxxxxx
    密码就是后面那串随机字符（每台机器不一样，只显示这一次，登录后马上改掉）
    （找不到就看 snowluma\logs\ 里当天的日志，或手动双击 snowluma\launcher.bat 看黑窗）
  - 浏览器打开  http://127.0.0.1:5099   （SnowLuma 控制台）
    用 admin + 初始密码登录 -> 先同意 EULA/隐私政策（面板此时还没解锁）
    -> 改掉 WebUI 密码 -> 登录要挂机器人的 QQ 号
  - 建一个 OneBot 网络：
        WS   服务端   ws://127.0.0.1:3000
        HTTP 服务端   http://127.0.0.1:3001
    （设了 access token 的话，两边必须填一样的）
  - 回到应用 -> 设置 -> OneBot（SnowLuma）-> 填同样地址和 token -> 保存设置
    状态栏显示「OneBot 已连接」就成功

第 3 步  配模型 + 白名单（不做这步 bot 不会说话）
  - 设置 -> 模型 API：选 DeepSeek / GLM / GPT -> 选模型 -> 填 API Key -> 保存并使用
  - 自定义接口在“其他”中添加；温度、思考等参数在“高级设置”中
        （DeepSeek 例：https://api.deepseek.com/v1 ，模型 deepseek-flash）
        点「测试连通性」绿灯 -> 点「保存设置」
  - 设置 -> 聊天白名单：填要它接活的群号
        ⚠ 留空 = 谁都不理（默认的安全设置，不是 bug）
        想让它全群都回，就打开「允许所有…」
  - 去群里 @ 它一下试试

----------------------------------------
【出问题先看这两条】

* bot 不理人：白名单空 / 档位太低 / 顶部点了「暂停」/ OneBot 未连接 / 模型 API 没配好

* 双击了没反应、窗口一闪就没：
  这个程序的单实例锁是共享的（package.json 里 name 都是 qq-agent，共用 %APPDATA%\qq-agent）。
  只要已经有一份在跑，后启动的那份会「静默退出」，不会有任何提示。
  解决：任务管理器里找到 electron.exe（路径带 QQ Agent / 新建文件夹）先退出，再启动这一份。
  ⚠ 永远不要同时开两份：会抢 3000 / 3001 / 5099 端口和同一个 QQ 号。

* 进不去 SnowLuma 控制台 / 忘了 WebUI 密码：
  删掉 snowluma\config\webui.json，重启程序 —— 会重新生成初始凭据并再次打印到
  data\logs\snowluma-console.log（搜 initial credentials），用 admin + 新密码登录后马上改。

更多问题（端口占用、搜图失败、换 QQ 号、备份迁移、怎么退出…）见同目录的
  使用说明.md
